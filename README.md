# YouTube Video Downloader

یک دانلودر ساده و کاربردی برای دانلود ویدیوهای YouTube با Python و `yt-dlp`.

## نصب

ابتدا وابستگی‌های پروژه را نصب کنید:

```bash
pip install -r requirements.txt
```
همچنین برای ترکیب صدا و تصویر به FFmpeg نیاز دارید.

اجرا

برنامه را اجرا کنید:
```bash
python main.py
```
سپس لینک ویدیو را وارد کنید. برنامه اطلاعات ویدیو و حجم تقریبی فایل را نمایش می‌دهد، برای دانلود تأیید می‌گیرد و در نهایت امکان انتخاب پوشه ذخیره‌سازی را فراهم می‌کند.

کاربران ایران

اگر در ایران هستید و YouTube از شبکه شما قابل دسترسی نیست، از یک VPN استفاده کنید.

توجه داشته باشید که VPN باید برای اتصال Python نیز فعال باشد. فعال بودن VPN فقط داخل مرورگر ممکن است برای yt-dlp کافی نباشد.
